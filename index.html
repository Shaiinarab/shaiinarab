// UNDER THE HOOD

How this page works

One static page, one public API, zero trackers. The directory is rebuilt in your browser on every visit, so new repositories show up without a redeploy.

  • Public GitHub data only — forks and this page's own repo are filtered out.
  • If the API is rate-limited or offline, a cached snapshot from your last visit keeps the page useful.
  • No cookies, no analytics, no CDNs — every script on this page ships from my own repo. The theme you pick is the only thing I remember.
  • Runtime layer: htmx 4.0.0 (preview line) drives the search trigger pipeline, Alpine 3.17 powers reactive islands, _hyperscript 0.9.93 handles declarative micro-behaviors, and Tailwind v4.3's browser build sits under my hand-written CSS. All four are vendored from unpkg — zero CDN calls, works offline.
